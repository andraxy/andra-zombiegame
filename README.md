# DEAD SIGNAL — ZOMBIE GAME MADE BY ANDRA

Semua file website berada langsung di root project. Tidak ada folder pembungkus dan tidak ada folder `api`.

## Deploy ke Vercel
1. Ekstrak ZIP.
2. Upload semua file yang ada langsung ke root repository GitHub.
3. Import repository di Vercel.
4. Framework Preset: Other. Build Command kosong. Output Directory: `.`.
5. Deploy.

Game bisa langsung dimainkan. Leaderboard lokal tersimpan di browser masing-masing.

## Mengaktifkan leaderboard online (Supabase)
1. Buat project Supabase.
2. Buka SQL Editor dan jalankan:

```sql
create table public.scores (
  id bigint generated by default as identity primary key,
  name text not null,
  score integer not null,
  wave integer not null,
  created_at timestamptz default now()
);

alter table public.scores enable row level security;

create policy "Public can read scores"
on public.scores for select
to anon
using (true);

create policy "Public can submit scores"
on public.scores for insert
to anon
with check (
  char_length(name) between 1 and 14
  and score >= 0 and score <= 100000
  and wave >= 1 and wave <= 10000
);
```

3. Buka `config.js`.
4. Ganti `PASTE_SUPABASE_PROJECT_URL` dengan Project URL Supabase.
5. Ganti `PASTE_SUPABASE_ANON_PUBLIC_KEY` dengan anon/public key Supabase.
6. Commit perubahan ke GitHub. Vercel akan deploy ulang.

Catatan: anon key memang boleh digunakan di frontend jika RLS aktif. Jangan gunakan `service_role` key. Skor dari browser tetap bisa dimanipulasi; ini leaderboard kasual, bukan anti-cheat kompetitif.
